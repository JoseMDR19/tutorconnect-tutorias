# TutorConnect — prototipo web navegable

Proyecto académico de interfaz realizado con HTML, CSS y JavaScript. Está preparado para publicarse como sitio estático.

## Archivos
- `index.html`: pantallas web y navegación.
- `css/styles.css`: estilos adaptables a escritorio y móvil.
- `js/app.js`: navegación, filtros y acciones demostrativas.

## Probar localmente
Abre `index.html` en un navegador. Para ver el proyecto online, sube al repositorio la carpeta completa conservando la estructura.

## Publicar en GitHub Pages
1. Crea un repositorio público en GitHub.
2. Sube `index.html`, la carpeta `css/` y la carpeta `js/` al directorio raíz.
3. Entra en **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**, la rama `main` y la carpeta `/(root)`.
5. Guarda, espera a que termine la publicación y copia la URL que GitHub muestre. No uses una URL hasta que aparezca publicada.

## Limitaciones
Es un prototipo front-end. Los perfiles, precios, calificaciones, reservas, mensajes e ingresos son datos ficticios. Los formularios no guardan datos en una base de datos. No existe autenticación real, envío de correos, pagos, videollamadas ni chat en tiempo real. El SQL debe diseñarse, ejecutarse y probarse por separado si el proyecto requiere una base de datos.
